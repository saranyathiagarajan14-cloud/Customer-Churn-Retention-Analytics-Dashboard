# Customer Churn & Retention Analytics Dashboard

## 📌 About the Project

This project analyzes customer churn and retention using Microsoft Excel. It contains 1,000 customer records and focuses on identifying churn patterns and customer retention factors.

## 🎯 Objectives

* Analyze customer churn and retention
* Calculate key business KPIs
* Identify churn patterns based on contract, tenure, internet service, and gender
* Create a visual dashboard for business insights

## 🛠️ Tools Used

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Charts & Data Visualization
* Data Cleaning
* Dashboard

## 📊 Key Results

* Total Customers: 1,000
* Churn Customers: 177
* Retained Customers: 823
* Churn Rate: 17.70%
* Retention Rate: 82.30%

## 📁 Workbook Includes

* Customer Churn Data
* Formula Analysis
* Pivot Tables
* KPI Calculations
* Churn Analysis Charts
* Interactive Dashboard

## 💡 Outcome

The project provides insights into customer churn patterns and helps identify areas where businesses can improve customer retention.
